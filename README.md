# Sonoran Demo Studio downloads

Download the current editor from the [latest release](https://github.com/Sonoran-Software/Sonoran-Demo-Studio-Releases/releases/latest).

| Device | Download |
| --- | --- |
| Windows | `Sonoran-Demo-Studio-windows-x64.exe` |
| Mac with Apple silicon | `Sonoran-Demo-Studio-arm64.dmg` |
| Mac with Intel processor | `Sonoran-Demo-Studio-x64.dmg` |

Run the installer, then open Sonoran Demo Studio and enter your Kara API key when connecting to your projects. The app's **Updates** section shows the installed version and has **Check for updates** and **Install and restart** controls. The app also checks automatically while it is running.

If you installed a version that used the private source repository for updates, install a release from this page once to switch to the public update feed. Future updates do not need GitHub access. This repository contains downloads and update manifests; the editor source is maintained separately.
